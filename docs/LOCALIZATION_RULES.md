# LeadLens Localization Rules

## ICP terminology — non-negotiable

Never display `ICP` by itself on first mention within a page, report view, or onboarding flow. Preserve the industry acronym and immediately explain it in the active language:

- English: `ICP (Ideal Customer Profile)`
- Spanish: `ICP (Perfil de Cliente Ideal)`
- Portuguese: `ICP (Perfil de Cliente Ideal)`
- Japanese: `ICP（理想顧客プロファイル）`

After that first expanded occurrence in the same user context, `ICP` alone is allowed when space requires it. Never insert the English expansion into Spanish, Portuguese, or Japanese UI. Apply this rule to landing, pricing, onboarding, tooltips, placeholders, plan descriptions, customer reports, account areas, and translated copy.

Do not rename backend fields, database columns, types, APIs, analytics keys, or other internal identifiers for localization.

Apply the same first-use expansion principle to other commercial acronyms that a general business user cannot reasonably be expected to understand. Every translation must use a correct local expansion rather than retaining an English definition.
