## Explicitly NOT built (guardrails, §10)
- **No contact database / named-contact enrichment as a product** — LeadLens is not Apollo. Named people only
  when public, current, relevant, non-inferred (§40); the durable output is *which function matters + how
  accessible + what to validate* (§41).
- **No legal/compliance opinion** — export/import requirements are a **commercial dependency map** with a
  specialist-confirmation disclaimer (§20/§29), never a guarantee.
- **No fabricated financial model** — price/margin are customer-provided facts + open questions, not modeled
  buyer margins (§46).
